# 试跑请求：最小主/子智能体联动演示

把 customagent 目录作为项目根目录打开后，在聊天框切换到主智能体 **qa-main**，发送：

```text
查询2026年亚运会女子100米冠军是谁？
```

## 预期表现

1. qa-main 自身没有 websearch 工具，识别出这是实时信息问题。
2. qa-main 通过 task 工具调用 web-searcher（回复中会显示被调用的子智能体名称）。
3. web-searcher 用 websearch 搜索并返回带来源的结果。
4. qa-main 汇总给出答案、来源链接和查询日期。

## 参考答案（2026-09-29 实测检索结果）

冠军是中国选手**陈妤颉**：2026年9月25日在日本名古屋举行的第20届亚运会（爱知·名古屋）女子100米决赛中，以 11秒06 夺金并打破赛会纪录；银牌 Shanti Pereira（新加坡，11秒21），铜牌 Edidiong Odiong（巴林，11秒33）。来源：Olympics.com、新华社、World Athletics。

这个问题的答案在模型训练数据之后，恰好用来证明"主智能体自己答不出来，必须靠子智能体联网"。
