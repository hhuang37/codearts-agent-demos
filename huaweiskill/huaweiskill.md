## What This Demo Shows

This demo uses the official **Skill Reviewer** to show how to install a Skill from the CodeArts Skill Marketplace and verify it by asking it to review another Skill.

## 1. Find a Skill in the Official Marketplace

Open CodeArts Agent settings and go to **Skills and Rules > Marketplace**. Set the source filter to **Official**, then find the Skill you want to install. The example below uses `skill-reviewer`; the screenshot shows it after installation.

![Skill Reviewer in the official CodeArts Skill Marketplace](image.png)

## 2. Install the Skill and Choose Its Scope

Click the **+** button beside the Skill, choose where to install it, and confirm:

- **Project**: Installs the Skill in the current project's `.codeartsdoer/skills` directory.
- **User**: Installs the Skill in the user's `~/.codeartsdoer/skills/` directory, where it is available to that user.

The screenshot below shows the **User** scope selected before installation.

![Choose the Skill installation scope](image-1.png)

## 3. Invoke the Skill

After installation, invoke `skill-reviewer` in a CodeArts Agent conversation and ask it to review `data-analysis`:

```text
use /skill-reviewer to give me a report about the following skill /data-analysis
```

Submit the example prompt:

![Submit a prompt to invoke Skill Reviewer](image-2.png)

During execution, CodeArts Agent invokes `skill-reviewer` and begins reviewing the target Skill:

![Skill Reviewer running](image-3.png)

## 4. Review the Results

The review checked 15 items: 9 passed, 5 had warnings, and 1 failed. The overall score was **85/100**, with a status of `pass_with_warnings`. This confirms that `skill-reviewer` responded and generated a review report.

![Review report generated by Skill Reviewer](image-4.png)
